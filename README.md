# sistema-control-inventario
Sistema para registrar productos, controlar stock y gestionar el inventario de un supermercado.
Descripción del proyecto

El proyecto consiste en desarrollar un sistema de gestión empresarial que permita organizar y administrar la información y los procesos de una organización. El objetivo es mejorar el control de las actividades, reducir errores y facilitar el acceso a la información.
Control de versiones

El proyecto utiliza Git y GitHub para registrar los cambios, trabajar con ramas secundarias y revisar las modificaciones mediante Pull Requests.
Declaración de uso de IA

Se utilizaron herramientas de inteligencia artificial como apoyo para organizar la documentación y proponer estructuras iniciales.
