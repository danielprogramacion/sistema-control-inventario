# sistema-control-inventario
Sistema para registrar productos, controlar stock y gestionar el inventario de un supermercado.
Descripción del proyecto

#DESCRIPCIÓN

El presente proyecto consiste en el desarrollo de un Sistema de Control de Inventario para un Supermercado, cuyo objetivo principal es mejorar la organización, el registro y el seguimiento de los productos disponibles en el establecimiento.

La administración del inventario es una tarea importante dentro de un supermercado, ya que permite conocer qué productos hay disponibles, qué cantidades quedan en el depósito y cuáles necesitan ser repuestos. Cuando estos procesos se realizan de forma manual o sin una organización adecuada, pueden producirse errores en los registros, pérdidas de información, faltantes de mercadería y dificultades para mantener actualizado el stock.

Por este motivo, se propone desarrollar un sistema informático que permita registrar y consultar los productos de manera ordenada, actualizar las cantidades disponibles y facilitar el control de las existencias.

#PROBLEMAS QUE BUSCA RESOLVER

El proyecto surge de la necesidad de mejorar el control de los productos que forman parte del inventario de un supermercado.

Entre los principales problemas que se busca reducir se encuentran:

Dificultad para conocer la cantidad disponible de cada producto.

Errores al registrar manualmente las entradas y salidas de mercadería.

Falta de actualización de las cantidades existentes.

Problemas para identificar productos con bajo nivel de stock.

Pérdida de tiempo al buscar información sobre los productos.

Dificultad para organizar las tareas relacionadas con el control de inventario.

La implementación de un sistema informático permitirá centralizar la información y facilitar las consultas, contribuyendo a una administración más organizada y eficiente.

#OBJETIVO GENERAL 

Desarrollar un sistema de control de inventario que permita administrar los productos de un supermercado, mantener actualizadas las cantidades disponibles y facilitar el seguimiento del stock para mejorar la organización de las tareas diarias.

#OBJETIVOS ESPECÍFICOS

Registrar los productos que forman parte del inventario.

Consultar la información de cada producto de manera sencilla.

Actualizar las cantidades disponibles cuando se produzcan movimientos de mercadería.

Facilitar la identificación de productos con pocas unidades.

Reducir los errores relacionados con el registro manual de información.

Mejorar la organización y el seguimiento de las existencias.

Mantener la información del inventario organizada y accesible para su consulta.
